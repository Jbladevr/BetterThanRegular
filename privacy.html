Privacy Policy

Last updated: August 2026

This application is a personal-use tool that connects to a single Pinterest account (the developer's own account) to create Pins automatically on that account's behalf. It is not distributed to or used by any other Pinterest users.

What data this app accesses

  • The Pinterest account's boards, for the purpose of creating Pins
  • Basic account information required by Pinterest's API to authenticate requests

What data this app does not do

  • It does not collect, store, or share data belonging to any other Pinterest user
  • It does not sell, rent, or transfer any data to third parties
  • It does not use Pinterest data for advertising or analytics purposes

Data storage

Authentication tokens are stored securely and privately for the sole purpose of maintaining the connection to this single account. No other personal or account data is retained.
